Safety model

The user stays in control.

  • Messages are reviewed and approved before Gmail actions occur.
  • NetworkPilot does not autonomously or bulk-send email.
  • There is no background scheduler or SMTP delivery path.

How it works

A focused workflow for professional outreach

01

Discover

Surface relevant professionals and recruiters for a user's job search.

02

Prepare and review

Generate personalized drafts for explicit human review and approval.

03

Act deliberately

Create a Gmail draft or send an already-approved message only after explicit user action.

04

Track outcomes

Keep outreach status and reported outcomes organized in the private local application.

Google and Gmail access

Access is limited to user-approved compose actions.

NetworkPilot requests the gmail.compose permission only to create Gmail drafts and send messages that the user has already reviewed and approved.

NetworkPilot does not read the Gmail inbox or message bodies, does not access Google Drive, and does not use Google user data for advertising or sell it.
