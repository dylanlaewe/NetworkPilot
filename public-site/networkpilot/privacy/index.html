NetworkPilot

Privacy Policy

Effective September 17, 2026

This policy explains how NetworkPilot processes information, including Google user data, in its private, single-user job-search networking workflow.

1. What NetworkPilot is

NetworkPilot is a private, locally operated job-search networking assistant. It helps a user identify relevant professionals and recruiters, prepare and approve outreach, create Gmail drafts, send already-approved messages after explicit user action, and track outreach outcomes. It does not autonomously or bulk-send email.

2. Information processed

NetworkPilot processes information the user provides or approves for professional outreach, such as candidate and company details, draft content, approval state, Gmail operation status, and user-reported outreach outcomes. Operational information is stored locally for the user's private workflow.

3. Google user data accessed

NetworkPilot requests the Google OAuth scope https://www.googleapis.com/auth/gmail.compose. This permission is used only for user-approved Gmail draft creation and sending. NetworkPilot does not read the user's Gmail inbox, does not read message bodies from Gmail, and does not access Google Drive.

4. How Google user data is used

Google user data is used only to provide NetworkPilot's user-facing Gmail compose features. A Gmail draft is created only after the user approves its content. An approved message is sent only after a separate, explicit user action. NetworkPilot does not use Gmail data for advertising, profiling, or any unrelated purpose.

5. Credential storage

Google OAuth credentials are stored locally in macOS Keychain. They are not embedded in this public site. The public site has no access to OAuth credentials, the private application database, or the user's outreach records.

6. Data sharing

NetworkPilot does not sell Google user data. It does not share Google user data with advertisers or data brokers. Information necessary to perform a user-approved Gmail action is transmitted to Google's Gmail API. The static public website is hosted by Cloudflare but does not receive or process NetworkPilot operational or Google user data.

7. Data retention

Local operational records are retained on the user's device until the user removes them through the application's supported local data-management workflow. OAuth credentials remain in macOS Keychain until the user disconnects NetworkPilot, removes them, or revokes access through the Google Account permissions page.

8. User control

The user reviews and approves message content before Gmail actions occur and initiates every send action. The user can revoke NetworkPilot's Google access at any time through Google Account settings and can remove locally stored credentials from macOS Keychain.

9. Security

NetworkPilot limits Google access to the Gmail compose scope, stores OAuth credentials in macOS Keychain, keeps operational data in the private local application, and separates this public static site from private runtime state. No system can guarantee absolute security, but NetworkPilot is designed to minimize access and keep the user in control.

10. Changes to this policy

This policy may be updated when NetworkPilot's behavior or privacy practices change. The effective date at the top of this page will be updated when material revisions are published.
